Ü1

Technische Umsetzung von Szenarien aus der Vorlesung zu Transaktionen und Isolation Levels in PostgreSQL.

Banküberweisung

  • Schreiben sie ein Python-Programm, das eine Banküberweisung auf einer PostgreSQL-Datenbank simuliert
  • Implementieren sie eine Variante des Programms ohne Transaktionen
  • Lassen sie das Programm mehrere Ausführungen der Überweisungen gleichzeitig ausführen
  • Produzieren sie Inkonsistenzen in den Kontoständendurch Crashen des PostgreSQL-Server während der Ausführung
  • Implementieren sie eine Variante des Programms mit Transaktionen
  • Crashen sie den PostgreSQL-Server während der Ausführung und zeigen sie, dass keine Inkonsistenzen auftreten
  • Achten sie auf die Verwendung der richtigen Bibliothek durch die KI (psycopg und nicht psycopg2)

Lost Update

  • Schreiben sie ein Python-Programm, das ein Lost Update-Szenario simuliert
  • Ändern sie den Code so, dass kein Lost Update mehr auftritt
  • Hinweis: Verwenden sie die richtige Isolationsebene in PostgreSQL

Write Skew

  • Schreiben sie ein Python-Programm, das ein Write Skew-Szenario simuliert
  • Ändern sie den Code so, dass kein Write Skew mehr auftritt
  • Hinweis: Verwenden sie die richtige Isolationsebene in PostgreSQL
