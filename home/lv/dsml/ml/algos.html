Linear Regression

Used for Regression

How it works

  • Fits a "best-fit" straight line (or hyperplane) through data points
  • Creates a linear relationship between features (X) and a target (Y).

Pros

  • Simple, highly interpretable, fast to train

Cons

  • Assumes linear relationships, sensitive to outliers
{% include padding-id.html id=2 %}

Logistic Regression

Used for Classification

How it works

  • Despite the name, it is used for classification
  • It models the probability of a binary outcome using a logistic function
  • It can be extended to handle multi-class classification problems
  • It is a linear model, making it easy to interpret and implement

Pros

  • Outputs interpretable probabilities

Cons

  • Prone to underfitting on complex, non-linear data.
{% include padding-id.html id=3 %}

Decision Trees

Used for Classification & Regression

How it works

  • Splits data into branches based on feature questions
  • E.g., "Is Age > 30?"
  • Greedy algorithm that makes locally optimal choices at each step

Pros

  • Easy to read and interpret

Cons

  • Performance can be poor with high-dimensional data
  • Prone to overfitting
{% include padding-id.html id=4 %}

Random Forests

Used for Classification & Regression

How it works

  • Builds hundreds of slightly different decision trees
  • Averages their predictions for regression
  • Majority vote for classification

Pros

  • Highly accurate
  • Handles non-linear data well
  • Requires little data preprocessing

Cons

  • Random Forests are "black boxes"
  • Harder to interpret than a single tree
{% include padding-id.html id=5 %}

Naive Bayes

Used for Classification

How it works

  • Based on Bayes' Theorem
  • $P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$
  • Calculates the probability of a data point belonging to a certain class
  • Assumes features are conditionally independent given the class

Pros

  • Extremely fast
  • Works remarkably well with high-dimensional text data

Cons

  • Independent features is rarely true in the real world
{% include padding-id.html id=6 %}

Support Vector Machines (SVM)

Used for Classification & Regression

How it works

  • Separates different classes by finding the optimal hyperplane
  • Support vectors are the data points that are closest to the hyperplane
  • Maximizes the "margin" (distance) between the hyperplane and the support vectors
  • Kernel Trick: Transform data into higher dimensions
  • Uses the Kernel Trick to find linear separators for non-linear data

Pros

  • Effective in high-dimensional spaces
  • Handles non-linear boundaries well with kernels

Cons

  • Computationally heavy, only suitable for relatively small datasets
  • Requires careful tuning of parameters
  • Requires additional work for multiple classes
{% include padding-id.html id=7 %}

k-Nearest Neighbors (k-NN)

Used for Classification & Regression

How it works

  • Doesn't build a model
  • Looks at the k nearest neighbors to make predictions
  • Averages the values of the k nearest neighbors for regression
  • Majority voting for classification

Pros

  • Very intuitive
  • Simple to implement
  • Naturally handles multi-class problems

Cons

  • Very slow during the prediction phase
  • highly sensitive to feature scaling and irrelevant features
{% include padding-id.html id=8 %}

Gradient Boosting (e.g., XGBoost, LightGBM)

Used for Classification & Regression

How it works

  • Builds decision trees sequentially
  • Each new tree is trained on errors made by the previous trees
  • Combines the predictions of all the trees to make the final prediction

Pros

  • Often the most accurate algorithm for structured/tabular data

Cons

  • Prone to overfitting
  • Requires careful hyperparameter tuning
  • Slower to train than Random Forests
